ATTRIBUTE WARS

A twin-stick shooter for Timex and ZX Spectrum computers. This page always runs the latest TAP built from main on an emulated Timex TC2068 by default — SCLD double buffering, PT3 soundtrack and AY effects — with the TC2048, Spectrum 128K and 48K a click away. Press the ▶ button on the display to start — the game boots with the PT3 soundtrack (browsers only allow audio after that click).

Move — 5/6/7/8 (cursor) or Kempston pad    Fire — 0, or aim with Q W E / A D / Z X C
…or plug in a real gamepad / joystick — the game reads it as a Kempston (press a button on the pad so the browser reveals it)

☕ Sponsor dtz-labs — support new ZX Spectrum software

Timex TC2068 Timex TC2048 Spectrum 128K Spectrum 48K

The Timex versions run on our fork of JSSpeccy 3, which adds the TC2048 and TC2068 video modes; stock JSSpeccy has no Timex support, so until now that build could only be downloaded. The 48K build flickers by design — no second display page. All TAPs are also in the releases.

Emulation by JSSpeccy 3 (GPL-3), in the dtz-labs fork with Timex support.
