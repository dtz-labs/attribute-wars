ATTRIBUTE WARS

A twin-stick shooter for Timex and ZX Spectrum computers. This page always runs the latest ZX Spectrum 128K TAP built from main, so the PT3 soundtrack and AY effects are audible. Press the ▶ button on the display to start — the game boots with the PT3 soundtrack (browsers only allow audio after that click).

Move — 5/6/7/8 (cursor) or Kempston pad    Fire — 0, or aim with Q W E / A D / Z X C

☕ Sponsor dtz-labs — support new ZX Spectrum software

The Timex TC2048/TC2068/TS2068 build (SCLD double buffering) is not playable here (JSSpeccy has no Timex modes) — grab it, and the 48K build, from the releases.
